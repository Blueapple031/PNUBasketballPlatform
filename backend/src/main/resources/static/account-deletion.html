계정 삭제 요청 방법

  1. 넉터(NUKTU) 앱에 로그인합니다.
  2. 마이페이지 → 설정 → 탈퇴를 선택합니다.
  3. 안내 내용을 확인하고 확인란에 탈퇴를 입력합니다.
  4. 계정 삭제를 누르면 요청이 즉시 처리됩니다.
계정 삭제는 취소하거나 복구할 수 없습니다. 필요한 정보는 삭제 전에 별도로 보관해 주세요.
