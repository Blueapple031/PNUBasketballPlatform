# [FE] 동아리 목록 -> 상세 페이지 네비게이션 구현

## ✨ 기능 설명 (Description)
- 동아리 탭 진입 시 동아리 목록을 보여주고, 사용자가 원하는 동아리 로고/이름을 선택하면 동아리 상세 페이지로 이동하는 흐름을 구현합니다.
- 기존 `#15`에서 만든 동아리 탭 스켈레톤을 재사용하고, 이번 이슈에서는 목록 선택과 라우팅 연결에 집중합니다.
- API 연동 전 단계에서는 더미/목업 데이터 기반으로 동작을 먼저 완성하고, 이후 API 교체가 쉬운 구조를 유지합니다.

## ✅ 구현 목표 (Acceptance Criteria)
### 1) Club List
- [ ] 동아리 탭에서 동아리 목록(로고, 이름)이 표시된다.
- [ ] 목록 아이템은 탭 가능한 UI로 제공된다.
- [ ] 빈 목록일 때 안내 UI가 표시된다.

### 2) Navigation
- [ ] 동아리 로고/이름 탭 시 상세 페이지로 이동한다.
- [ ] 선택한 동아리 식별자(`clubId` 또는 `slug`)가 상세 페이지로 전달된다.
- [ ] 뒤로가기 시 동아리 목록 화면으로 정상 복귀한다.

### 3) Club Detail (Skeleton Reuse)
- [ ] 기존 동아리 상세 스켈레톤 화면이 라우팅 대상으로 연결된다.
- [ ] 전달받은 동아리 기준으로 제목/로고 등 최소 1개 이상 고유 정보가 표시된다.
- [ ] 잘못된 파라미터 전달 시 안전한 fallback UI가 표시된다.

### 4) Interaction & State
- [ ] 빠른 연속 탭에서도 중복 네비게이션이 발생하지 않는다.
- [ ] 목록 스크롤 상태가 기본적으로 자연스럽게 유지된다.

### 5) Design/System
- [ ] design.md 기준 컴포넌트/토큰 사용 원칙을 유지한다.
- [ ] 하드코딩 최소화 및 재사용 가능한 위젯 구조를 유지한다.
